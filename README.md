One funny line a hopeless tech support agent says to a desperate customer — 107 characters, one line, plain text.

> Good news — I've escalated your case to Tier 2. Bad news — Tier 2 is also me, but with a different headset.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program writes the line to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt`) with no network access; two runs write
identical bytes.
